# Action sound sources

All downloaded sources below are offered under CC0. These are short edited sound effects, played once per accepted action. The existing background music remains separate.

| Action | Source files | Creator and source |
|---|---|---|
| Play | squeak toy - squeak2.wav, squeak toy - squeak1.wav | bart: https://opengameart.org/content/squeak-toy-sounds |
| Study | bookFlip1.ogg, bookFlip2.ogg, bookFlip3.ogg | Kenney: https://kenney.nl/assets/rpg-audio |
| Eat | crunch.1.ogg, crunch.3.ogg, crunch.5.ogg | Tito and StarNinjas: https://opengameart.org/content/7-eating-crunches |
| Sleep | cloth1.ogg, cloth3.ogg | Kenney: https://kenney.nl/assets/rpg-audio |

Source pages and the Kenney included license were checked on October 10, 2026. Sources were converted to mono 44.1 kHz 16-bit WAV, trimmed, faded at the edges and mixed into short action sequences. Peaks are limited to 0.65 before the existing AudioSource volume. Study turns pages; Sleep rustles a blanket, without a repeated jingle.

The four resulting clips replace `Assets/Audio/Music/play.wav`, `study.wav`, `feed.wav` and `sleep.wav`, preserving existing Unity asset GUIDs and scene AudioSource references.
